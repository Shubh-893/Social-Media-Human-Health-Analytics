# SOCIAL MEDIA: THE HEALTH CRISIS

A data analytics project exploring the **impact of social media usage on human health**, with a focus on **sleep, anxiety, productivity, screen time, and emotional well-being**.

This project was developed as part of the **IBM SkillsBuild Summer Internship Program with CSRBOX**, a **6-week Data Analytics internship** completed from **14 June 2026 to 27 July 2026**. The analysis combines data preprocessing, exploratory analysis, sentiment analysis, and interactive visualization to derive meaningful insights from social-media-related health data.

## About the Project

The increasing use of social media has raised concerns about its influence on mental and physical well-being, particularly among young users. This project analyzes available data to understand patterns between **social media usage and health-related outcomes**.

The analysis focuses on:

* The relationship between **social media usage and anxiety**
* The impact of **screen time and night-time usage on sleep quality**
* The relationship between social media consumption and **productivity / academic focus**
* Patterns in **emotional well-being and negative sentiments**
* Sentiment trends associated with different levels of social media usage

## Project Workflow

The project follows an end-to-end data analytics workflow:

**Data Collection → Data Cleaning → Data Preprocessing → Exploratory Data Analysis → Sentiment Analysis → Visualization → Dashboard Development → Insights**

## Key Insights

The analysis highlighted several important patterns related to social media usage and well-being:

* Higher levels of social media usage were associated with **increased anxiety and negative emotional outcomes**.
* **Night-time screen usage** showed a relationship with poorer sleep quality and reduced focus.
* Users with higher social media consumption showed greater prevalence of **negative emotional indicators such as sadness, comparison, and burnout**.
* Data-driven visualization helped identify patterns between **screen time, emotional health, sleep, and productivity**.
